# 🍓 果趣订单 (Fruit Order Fun)

一款休闲水果合成消除游戏的可玩 MVP，根据原型图开发。

> 轻松合成，完成水果订单！

## 🎮 玩法

木箱中堆满了水果（带物理堆叠效果）。**拖动水果，把 3 个以上同类水果凑到一起即可消除**。在限定时间内消除指定数量的目标水果，完成订单即可通关。

- **订单目标**：顶部显示需要消除的水果种类与数量（如 🍉 x3）
- **连击**：连续快速消除可累积连击倍率，大幅提升得分
- **计时**：时间耗尽且未完成订单则挑战失败，可花费 💎 复活续命
- **星级**：剩余时间越多，获得的星星越多（最高 3 星）

## 🧰 道具与特殊水果

| 道具 | 效果 |
|------|------|
| 🔀 洗牌 | 重新打乱所有水果的种类 |
| 🔨 敲一敲 | 点击敲碎任意一个水果 |
| 🧲 磁铁 | 一键吸取并消除场上所有目标水果 |
| 🌈 彩虹果 | 可代替任意水果参与消除 |
| 💥 星星炸弹 | 拖动消除时引爆，清除周围一圈水果 |

## 🗺️ 界面

- **主菜单**：当前订单预览、开始游戏、底部导航（关卡 / 每日奖励 / 签到 / 商店）
- **关卡地图**：蜿蜒小路式关卡选择，已通关解锁后续关卡
- **核心玩法**：木箱 + 物理水果堆 + 订单 / 计时 / 道具
- **结算**：胜利（星级、得分、连击、奖励）/ 失败（复活、重开、返回）

## 🚀 运行

纯前端，无需构建。直接用浏览器打开 `index.html` 即可（推荐手机竖屏 / 浏览器移动端模拟）。

```bash
# 任选其一启动本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 📁 结构

```
index.html        页面结构 + 所有界面（菜单/地图/玩法 HUD/结算弹窗）
css/style.css     卡通果园风格样式
js/physics.js     自研轻量圆形物理引擎（重力/碰撞/拖拽/连通分量）
js/game.js        游戏主逻辑（关卡/订单/消除/道具/计分/结算/界面管理）
```
